# Visión del producto

## Propuesta de valor
Centralizar en una sola plataforma la operación completa de redes sociales de negocios, creadores, equipos y agencias:
- planificación;
- generación asistida por IA;
- adaptación multicanal;
- colaboración y aprobación;
- programación/publicación;
- inbox donde las APIs lo permitan;
- analítica;
- aprendizaje de resultados;
- automatización.

## Segmentos
1. Emprendedores y pequeños negocios.
2. PyMEs con equipo de marketing.
3. Community managers independientes.
4. Agencias con múltiples clientes/marcas.
5. Empresas con flujos de aprobación y compliance.

## Diferenciadores
- Multi-brand real.
- Roles y permisos granulares por Organization y acceso por Brand.
- Motor agnóstico de IA.
- Motor agnóstico de redes sociales.
- Billing con Stripe, Mercado Pago y Openpay activables desde SUPERADMIN.
- Flujos de aprobación configurables.
- Automatizaciones.
- Seguridad como capacidad central.
- API pública y MCP en fases posteriores.

## Flujo principal
Registro -> verificación -> Organization -> trial/plan -> Brand -> conexión OAuth -> Brand Brain -> crear contenido -> variantes por red -> aprobación -> programación -> publicación -> métricas -> AI Insights.
